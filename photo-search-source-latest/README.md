# ФотоПоиск — исходный код

Полная копия клиентского исходного проекта в отдельной папке репозитория.

## Состав
- `index.html` — точка входа;
- `js/` — JavaScript-модули приложения;
- `style.css` — стили интерфейса;
- `config.json` — параметры группы и разрешённые альбомы;
- `vendor/vk-bridge.js` и лицензия VK Bridge;
- `privacy.html`, `terms.html`, `legal.css` — правовые страницы.

В конфигурации сохранена группа `173909287` и актуальный список из 22 альбомов в порядке меню.

## Важно
Эта папка — отдельная копия исходников для удобной работы и хранения. Рабочая папка `client/` не изменена; существующий путь публикации приложения не переключался на новую папку.
