Политика конфиденциальности

Приложение «Фотоальбомы» · редакция от 29 сентября 2026 года

Настоящая политика описывает обработку данных в VK Mini App «Фотоальбомы» (далее — «Приложение»). Оператором Приложения является владелец Приложения и администратор сообщества VK ID 173909287.

1. Какие данные используются

Приложение получает данные только в объёме, необходимом для заявленных функций просмотра и поиска фотографий:

  • идентификатор пользователя VK, имя и фамилия, предоставляемые VK Bridge;
  • параметры запуска Mini App, включая идентификатор сообщества, если Приложение запущено из сообщества;
  • временный access token VK с разрешением photos, если пользователь предоставил такое разрешение;
  • метаданные доступных пользователю или сообществу фотоальбомов и фотографий, получаемые через официальные методы VK API;
  • поисковые запросы, которые пользователь вводит в поля поиска внутри Приложения.

2. Для чего используются данные

Данные используются исключительно для работы функций Приложения: определения текущего пользователя или сообщества, отображения доступных альбомов и фотографий, локального поиска по названиям альбомов и описаниям фотографий, открытия объектов во ВКонтакте, копирования ссылок и загрузки выбранной пользователем фотографии.

3. Где и как хранятся данные

Приложение не имеет собственной серверной базы пользовательских данных. Access token, список альбомов, фотографии и результаты поиска хранятся только в оперативной памяти текущего запуска страницы и не записываются Приложением в IndexedDB или постоянный localStorage. После закрытия или перезагрузки Mini App эти данные текущей сессии удаляются из памяти страницы.

Статические файлы Приложения размещаются на GitHub Pages. Хостинг может самостоятельно обрабатывать обычные технические данные сетевого запроса (например, IP-адрес, User-Agent, время обращения) в соответствии со своими правилами. Приложение не использует эти сведения для профилирования пользователей.

4. Передача данных третьим лицам

Приложение не продаёт пользовательские данные, не передаёт их рекламным или аналитическим сервисам и не использует сторонние системы аналитики. Обмен данными, необходимый для основных функций, происходит между страницей Mini App и инфраструктурой VK через VK Bridge и официальные методы VK API.

5. Поисковые запросы

Текст, введённый в поля поиска, обрабатывается локально в браузере пользователя. Приложение не отправляет поисковые фразы на собственный сервер и не сохраняет историю поиска.

6. Разрешение на фотографии

Если VK запрашивает разрешение photos, пользователь самостоятельно принимает решение о его предоставлении. Разрешение используется для чтения доступных через VK API фотоальбомов и фотографий в рамках функций Приложения. Пользователь может управлять выданными приложению разрешениями средствами ВКонтакте.

7. Что Приложение не собирает

Приложение не запрашивает номер телефона, адрес электронной почты, геолокацию, личные сообщения, список контактов, платёжные данные и иные сведения, не необходимые для просмотра и поиска фотографий.

8. Безопасность

Access token не сохраняется в постоянном хранилище и не включается в публичные конфигурационные файлы. Приложение использует локальную копию VK Bridge и не загружает исполняемый код VK Bridge со стороннего CDN во время работы.

9. Удаление данных

Поскольку Приложение не создаёт собственной постоянной базы пользовательских данных, отдельное удаление данных с серверов Приложения обычно не требуется. Данные текущей сессии исчезают при закрытии или перезагрузке Mini App. Для изменения или отзыва разрешений VK используйте средства управления приложениями и разрешениями во ВКонтакте.

10. Изменения политики

Политика может обновляться при изменении функций Приложения или требований платформы. Актуальная версия всегда размещается по текущему адресу этой страницы.

11. Контакты
