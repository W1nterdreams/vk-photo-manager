Настоящее соглашение регулирует использование VK Mini App «Фотоальбомы» (далее — «Приложение»). Используя Приложение, пользователь подтверждает, что ознакомился с настоящим соглашением и Политикой конфиденциальности.

1. Назначение Приложения

Приложение предназначено для просмотра доступных пользователю или сообществу фотоальбомов и фотографий, поиска по названиям альбомов и описаниям фотографий, открытия соответствующих страниц во ВКонтакте, копирования ссылок и загрузки выбранных изображений.

Приложение показывает только те данные, которые VK API возвращает текущему пользователю в соответствующем контексте запуска. Доступность альбомов и фотографий зависит от настроек приватности, прав пользователя, настроек сообщества и работы платформы ВКонтакте.

Пользователь обязуется использовать Приложение законно, не пытаться обходить ограничения доступа, нарушать работу VK API, получать чужие данные без разрешения, распространять вредоносный код или использовать функции Приложения для нарушения прав третьих лиц.
