# Пряжа: выкладки — Android prototype 0.2.8

Локальный Android-блокнот для подготовки карточек пряжи перед публикацией в VK.

## Реализовано
- список выкладок по датам;
- создание выкладки с выбором даты, сегодня открывается по умолчанию;
- карточки пряжи внутри выкладки;
- все поля необязательные;
- поля: название, производитель, цвет, оттенок, состав, метраж (м/100 г), параметры нити, наличие (г), цена (₽/100 г), свободное описание;
- сохранение в локальную SQLite-базу;
- дублирование существующей карточки;
- копия сразу создаётся в базе со статусом `НЕ СОХРАНЕНА` и открывается для редактирования;
- поиск внутри выкладки;
- поиск по всей базе;
- копирование сформированной карточки в буфер обмена для вставки в VK;
- удаление карточки.

## Сборка
Проект рассчитан на Android Gradle Plugin 9.4.0, compileSdk 36, JDK 17.
Откройте папку проекта в Android Studio и выполните Build > Build APK(s).

`app/build/outputs/apk/debug/app-debug.apk` — ожидаемый путь debug APK после сборки.

## База
Файл SQLite создаётся приложением автоматически как `yarn_notebook.db` во внутреннем хранилище приложения.
