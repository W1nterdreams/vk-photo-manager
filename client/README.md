# VK Photo Client

Клиентская версия VK Mini App для просмотра и поиска фотографий в альбомах сообщества.

## Что умеет

- показывает только разрешённые альбомы домашней группы;
- для других незаблокированных групп показывает все обычные фотоальбомы их сообщества;
- поддерживает `blocked_group_ids`;
- две строки поиска на главном экране:
  - поиск альбомов;
  - поиск фотографий;
- если заполнены обе строки, фото ищутся только внутри найденных альбомов;
- поиск фото идёт по отдельным словам с условием И;
- результаты фото выводятся порциями по 10 карточек;
- просмотр фото со стрелками;
- долгое нажатие: скачать, скопировать ссылку, перейти к комментариям;
- комментарии открываются в нативном VK.

## Поиск фотографий и API

Постоянного IndexedDB-индекса больше нет.

При первом поиске фотографий в текущем запуске приложение получает фотографии нужных альбомов через `photos.get` и хранит их только в оперативной памяти. Повторные поиски по уже загруженным альбомам выполняются локально и не расходуют API. Если строка поиска альбомов ограничивает область поиска, загружаются только эти альбомы.

После закрытия/перезапуска приложения временные данные поиска исчезают. Кнопка обновления принудительно перечитывает нужные альбомы с VK.

## Доступ к фотографиям пользователя

Клиентское приложение не запрашивает scope `photos`, потому что оно не работает с личными фотографиями пользователя. Для вызова публичных методов VK API используется токен без специальных прав.

## Настройка

Основные параметры находятся в `config.json`:

- `home_group_id` — домашнее сообщество;
- `home_group_album_ids` — список альбомов, доступных в домашней группе;
- `blocked_group_ids` — сообщества, в которых приложение не должно работать.
