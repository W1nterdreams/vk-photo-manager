# VK Photo Client

Клиентский VK Mini App для просмотра альбомов и поиска фотографий.

## Логика сообществ

Приложение определяет сообщество по `vk_group_id`, который VK передаёт при запуске из сообщества.

- Для нашей группы (`home_group_id`) показываются и индексируются только альбомы из `home_group_album_ids`.
- Для любой другой незаблокированной группы приложение использует все доступные обычные фотоальбомы этой группы.
- Группы из `blocked_group_ids` не могут запустить приложение: проверка выполняется до запроса access token и до вызовов VK API.
- При прямом запуске без `vk_group_id` приложение использует `home_group_id`.

### Как заблокировать сообщество

Добавьте ID сообщества без минуса:

```json
"blocked_group_ids": [
  123456789
]
```

Можно указать несколько:

```json
"blocked_group_ids": [
  123456789,
  987654321
]
```

### Как изменить альбомы нашей группы

Меняется только массив:

```json
"home_group_album_ids": [
  282549589,
  282549604
]
```

У других незаблокированных сообществ этот массив не применяется — для них загружается список всех доступных обычных альбомов их сообщества.

## Поиск

Запрос `синий шерсть` означает логическое И: фотография должна содержать и `синий`, и `шерсть`. Порядок слов не важен. Регистр и `ё/е` не учитываются.

Поиск по уже загруженным данным выполняется локально и не расходует VK API.

## Экономия VK API

- Наша группа: список альбомов сообщества запрашивается одним `photos.getAlbums` (если их меньше 1000), после чего локально оставляются только ID из `home_group_album_ids`. Фото загружаются только из этих разрешённых альбомов.
- Другие группы: список их альбомов получается через `photos.getAlbums` крупными страницами.
- Типичный альбом до 1000 фотографий: один `photos.get`.
- Поиск внутри уже загруженного альбома: 0 API.
- Просмотр и перелистывание уже загруженных фотографий: 0 API.
- Комментарии внутри приложения не загружаются; кнопка открывает фотографию в нативном VK.
- Глобальный поиск использует IndexedDB и при последующих проверках перечитывает только изменившиеся альбомы.

В консоли доступны счётчики:

```js
vkApiDebug.stats()
vkApiDebug.reset()
```

## Важное ограничение блокировки

`blocked_group_ids` запрещает штатный запуск этого Mini App из указанного сообщества. Так как фронтенд размещён как статический JavaScript, это не является защитой исходного кода от копирования или модификации третьей стороной.


### Исправление client04
Для `photos.getAlbums` больше не передаётся параметр `album_ids`: это устраняет ошибку `album_ids not integer` в VK Mini Apps. Ограничение домашней группы выполняется локально после получения списка альбомов.
