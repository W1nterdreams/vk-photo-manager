# VK Photo Client

Клиентский VK Mini App для просмотра и поиска фотографий только в разрешённых альбомах сообщества.

## Что нужно настроить

Откройте `config.json`.

```json
{
  "vk_app_id": 0,
  "group_id": 173909287,
  "allowed_album_ids": [111111, 222222, 333333],
  "album_metadata_ttl_minutes": 30,
  "album_session_fresh_seconds": 60,
  "global_index_check_minutes": 30
}
```

- `vk_app_id`: можно оставить `0`, если приложение всегда запускается из VK — ID будет взят из параметра `vk_app_id` в URL. Для прямого запуска страницы можно вписать ID клиентского VK Mini App.
- `group_id`: ID сообщества без минуса.
- `allowed_album_ids`: только эти альбомы пользователь увидит и только по ним будет выполняться глобальный поиск.
- `album_metadata_ttl_minutes`: как долго список/метаданные альбомов можно использовать локально до фоновой сверки.
- `album_session_fresh_seconds`: сколько секунд уже загруженный альбом считается свежим в текущем сеансе.
- `global_index_check_minutes`: интервал между проверками, какие разрешённые альбомы изменились для глобального поиска.

## Поиск

Запрос `синий шерсть` означает логическое И: фотография должна содержать и `синий`, и `шерсть`. Порядок слов не важен. Регистр и `ё/е` не учитываются.

## API

- список до 1000 разрешённых альбомов: обычно 1 `photos.getAlbums`;
- типичный альбом до 1000 фото: 1 `photos.get`;
- прокрутка и поиск внутри уже загруженного альбома: 0 API;
- просмотр/перелистывание уже загруженных фото: 0 API;
- комментарии внутри приложения не запрашиваются;
- глобальный индекс после первой сборки проверяет метаданные и перечитывает только изменившиеся альбомы.

В консоли доступно:

```js
vkApiDebug.stats()
vkApiDebug.reset()
```
