# VK Photo Client

Клиентский VK Mini App для просмотра и поиска фотографий сообщества.

## Главный экран

На главном экране две строки поиска:

1. **Поиск альбомов** — фильтрует альбомы по словам.
2. **Поиск фотографий** — ищет фотографии по словам в описании.

Логика:

- обе строки пустые → показываются альбомы;
- заполнен только поиск альбомов → показываются найденные альбомы;
- заполнен только поиск фотографий → поиск фото по всем доступным для группы альбомам;
- заполнены обе строки → фотографии ищутся только в альбомах, прошедших первый фильтр.

Поиск по нескольким словам работает с условием **И**: `синий шерсть` означает, что в описании должны присутствовать оба слова независимо от порядка.

Фото выводятся крупной сеткой: 2 колонки на телефоне; первая порция — 10 фотографий. На более широком экране — 3 колонки.

## Группы

В `config.json`:

- `home_group_id` — наша группа;
- `home_group_album_ids` — альбомы, доступные в нашей группе;
- `blocked_group_ids` — группы, которым приложение запрещено.

Для других незаблокированных групп используются все обычные фотоальбомы их сообщества.

## API

Клиент использует только публичные методы:

- `photos.getAlbums`
- `photos.get`

После загрузки данные поиска обрабатываются локально. Индекс фотографий хранится в IndexedDB.
