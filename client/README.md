# VK Photo Client

Клиентская версия VK Mini App для просмотра и поиска фотографий.

## Контекст запуска

- группа `173909287` — показываются только 19 альбомов из `home_group_album_ids`;
- группа `164747280` — доступ запрещён через `blocked_group_ids`;
- любая другая разрешённая группа — показываются все доступные её фотоальбомы, включая системные;
- прямой запуск Mini App — показываются все доступные фотоальбомы текущего пользователя, включая системные.

Контекст группы берётся прежде всего через `VKWebAppGetLaunchParams`; query-параметры URL используются только как запасной вариант.

## Альбомы

Список альбомов теперь не сохраняется в постоянный `localStorage`: каждый новый запуск получает свежий список именно текущего владельца через `photos.getAlbums`.

`need_system=1`, поэтому для обычных пользователей и групп запрашиваются также системные альбомы. Пустой альбом, если VK API возвращает его текущему пользователю, отображается карточкой-заглушкой без обложки.

Пагинация выполняется порциями по 100 до достижения `response.count`, поэтому список не должен обрезаться первой страницей.

## Поиск фотографий

Постоянного IndexedDB-индекса нет. Фотографии нужных альбомов загружаются в оперативную память текущего запуска и повторно используются для следующих запросов.

Для обычных альбомов используется `photos.get`. Для системных альбомов приложение один раз за сеанс получает `photos.getAll` с включёнными service albums и затем локально разделяет фотографии по `album_id`.

## Авторизация

Для текущей статической архитектуры вызовы методов фотографий идут через пользовательский access token с `scope=photos`.

## Диагностика

В консоли доступны:

```js
vkApiDebug.stats()
vkApiDebug.context()
```

`context()` показывает фактический `vk_group_id`, `ownerId`, режим ограничения и список альбомов, который вернул VK.
