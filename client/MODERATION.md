# Подготовка к модерации VK Mini App

Перед отправкой приложения на модерацию:

1. Опубликуйте текущую сборку по HTTPS.
2. Проверьте, что открываются:
   - `privacy.html` — Политика конфиденциальности;
   - `terms.html` — Пользовательское соглашение.
3. В настройках VK Mini App укажите абсолютный URL политики конфиденциальности и абсолютный URL пользовательского соглашения.
4. Проверьте запрос разрешения `photos`: это единственное специальное разрешение, необходимое текущей клиентской архитектуре для чтения доступных фотоальбомов через VK API.
5. Проверьте прямой пользовательский запуск и запуск из разрешённого сообщества.
6. Если для модерации временно отключён белый список групп, после завершения модерации обязательно верните проверку доступа.
7. После каждого изменения файлов увеличивайте `CACHE_VERSION`, чтобы VK/WebView не использовал старую сборку.

## Что приложение обрабатывает

- VK user ID, имя и фамилию из VK Bridge;
- контекст запуска и `vk_group_id`, если приложение открыто из сообщества;
- access token с `photos` только в памяти текущей страницы;
- доступные через VK API альбомы и фотографии;
- поисковые фразы только локально в браузере.

## Что приложение не делает

- не имеет backend-базы пользовательских данных;
- не сохраняет токен в постоянное хранилище;
- не ведёт историю поисковых запросов;
- не подключает стороннюю аналитику;
- не загружает VK Bridge с CDN во время работы.
